PLOT TYPE 3: Delta RMSE (Model Comparison)
─────────────────────────────────────────
File: METHOD_NAME/delta_rmse/DeltaRMSE_M0X_M0X_EFP_WINDOW.png
Format: SINGLE PLOT with 3 SIDE-BY-SIDE PANELS

Metrics Used:
  ✓ Absolute Mortality (deadwood, %)
    → PANEL 1 (LEFT): Stratified by abs_mort categories
    
  ✓ Relative Mortality (deadwood / forest × 100, %)
    → PANEL 2 (CENTER): Stratified by rel_mort categories

What it shows:
  Y-axis: Delta RMSE = RMSE(with Disturbance) - RMSE(without Disturbance)
  X-axis: Categories (Low/Mid/High etc.)
  Horizontal line at Y=0 separates improvement from degradation

  • M02 vs M01 (C vs C+D)     → 10 plots (5 EFPs × 2 windows)

  • M06 vs M05 (C+M vs C+M+D) → 10 plots (5 EFPs × 2 windows)
  • M08 vs M07 (C+T+M vs C+T+M+D) → 10 plots (5 EFPs × 2 windows)

KEY TAKEAWAY
================================================================================

✓ Every analysis plot (except the root comparison plots) includes ALL THREE
  mortality metrics for comparison.

✓ This allows you to evaluate whether disturbance effects are:
  - CONSISTENT across different mortality metrics (robust finding)
  - VARIABLE depending on which metric you use (metric-dependent effect)

✓ Comparing the 3 panels/rows tells you about METRIC ROBUSTNESS
  Comparing across the 3 method folders tells you about METHOD ROBUSTNESS
