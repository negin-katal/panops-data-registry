Overview

This analysis examines how disturbance metrics influence ecosystem flux predictions at individual flux tower sites. Using SHAP (SHapley Additive exPlanations) values, we quantify the contribution of disturbance variables (Absolute Mortality, Relative Mortality, Relative Disturbance) to model predictions across different time lags and response variables.

Key Insight

Disturbance impact is stratified by disturbance level: Sites with high disturbance show stronger SHAP values for disturbance metrics, indicating these variables have greater influence on predictions where disturbance actually occurs. This mechanistic response validates the disturbance–flux relationship.

Disturbance Metrics Explained

1. Absolute Mortality

Definition: Percentage of deadwood in the pixel (0–100%)

Absolute Mortality (%) = (Deadwood area) / (Total area) × 100

Interpretation: Direct measure of deadwood extent. Higher values indicate more dead biomass.

2. Relative Mortality

Definition: Deadwood as a proportion of tree cover (0–100%)

Relative Mortality (%) = (Deadwood area) / (Live tree cover) × 100

Interpretation: Mortality intensity relative to live tree density. Accounts for background tree cover variations.

3. Relative Disturbance

Definition: Combined impact of deadwood and tree loss, normalized by forest extent

Relative Disturbance (%) = (Deadwood + Tree loss) / (Original forest + Tree loss) × 100

Interpretation: Total disturbance magnitude including both mortality and loss processes. Ranges 0–100%.

Buffer Radii

Each metric is calculated at five buffer distances around the flux tower: 100m, 200m, 300m, 400m, 500m. Different buffers capture disturbance at multiple spatial scales relevant to ecosystem processes.

What SHAP Values Tell Us

SHAP Interpretation

SHAP (SHapley Additive exPlanations) values quantify each feature's contribution to individual predictions:

  • Magnitude: Larger |SHAP| values = stronger influence on predictions
  • Direction: Positive SHAP = feature increases prediction; Negative SHAP = feature decreases prediction
  • Site-specificity: SHAP values are calculated per-site, showing localized disturbance effects
  • Model-agnostic: Works with any model type (Random Forest, neural networks, etc.)

Why SHAP Matters Here

SHAP values reveal whether disturbance metrics are mechanistically important (larger effects at disturbed sites) or spuriously correlated (similar effects everywhere). This validation is critical for establishing causal relationships.

Expected Patterns

Carbon Fluxes (GPPsat, NEPmax)

Expected: Large SHAP values at HIGH disturbance sites Rationale: Disturbance reduces photosynthetic capacity → must be included in predictions Pattern: Clear visual separation (tall boxes in T3, short in T1)

Water Fluxes (ETmax, uWUE, WUE)

Expected: Similar SHAP values across all disturbance levels Rationale: Water availability driven by climate, not disturbance level Pattern: No separation by tertile (uniform height across T1–T3)

Temporal Lags Explained

12-Month Lag

Disturbance effects from the previous year (t-1). Captures immediate legacy effects of mortality on current year fluxes.

24-Month Lag

Disturbance effects from two years prior (t-2). Reveals whether disturbance impacts persist or decay over longer timescales.

Key Question

Do disturbance effects fade? Comparing 12m vs. 24m SHAP values reveals the temporal persistence of disturbance influence on ecosystem fluxes.

Methods Summary

Cross-Validation Strategy

Leave-One-Site-Out (LOSO): For each of 113 sites, train the model on 112 sites and predict for the held-out site. This ensures SHAP values reflect true generalization (not training set overfitting).

Disturbance Stratification

Tertile Categories: Sites divided into three equal-sized groups (Low, Mid, High) based on disturbance percentiles (33.33%, 66.67%). This approach is statistically robust and avoids arbitrary thresholds.

Data Filtering

Tree-cover threshold: Sites with <30% tree cover removed (71 sites). Remaining 113 sites are sufficiently forested to isolate disturbance effects from background canopy variations.
